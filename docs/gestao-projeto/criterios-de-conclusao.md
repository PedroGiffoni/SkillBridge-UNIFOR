# Critérios de conclusão

## Pronto para iniciar

- [ ] Objetivo, contexto, sprint, categoria e prioridade definidos.
- [ ] Critérios de aceitação compreendidos e verificáveis.
- [ ] Dependências identificadas e capacidade confirmada.
- [ ] Responsável confirmado pela equipe e esforço estimado quando pertinente.

## Definition of Done

- [ ] Checklist e critérios específicos da Issue atendidos.
- [ ] Entregável acessível e versionado ou vinculado.
- [ ] Revisão real registrada por integrante confirmado.
- [ ] Evidência identificada com data real e link rastreável.
- [ ] Documentação atualizada e limitações registradas.
- [ ] Para código: testes apropriados executados, resultados reais e falhas documentadas; nenhum segredo versionado.
- [ ] Para interface: responsividade, teclado, contraste e preferência por movimento reduzido verificados.
- [ ] Para IA: respostas orientativas, JSON validado, chave no backend, erros e modo demo explícitos verificados.
- [ ] Para pesquisa: consentimento, minimização de dados e anonimização; contagem somente de participantes reais.
- [ ] Relatório da sprint e estado do quadro atualizados.

## Evidências e entrega acadêmica

SB-21 exige pelo menos 10 participantes reais; SB-22 exige cinco ou mais evidências reais e autorizadas. SB-23 só pode gerar gráficos com dados efetivamente coletados. Não confundir testes técnicos com participantes. Não inventar brainstorming, reuniões, assinaturas, métricas ou resultados. Não publicar dados pessoais desnecessários. Preparar relatório e anexos, revisar e submeter no Dream Shape até 27/11/2026; guardar comprovante real quando existir.
